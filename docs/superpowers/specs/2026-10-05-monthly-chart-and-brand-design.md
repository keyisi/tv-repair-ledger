# 月度经营图表与维修品牌设计

## 目标

在经营统计「按月」标签页加入与「按日」一致的收入/利润双柱状图，并提供 6 月、12 月、全部三种时间范围；在维修记录中新增「品牌」字段，并贯穿录入、列表、搜索、常用项管理、Excel 导入导出与备份，保证导出后再导入不丢数据。

## 界面设计

### 按月图表

「按月」标签页在「全部经营数据」总览下方依次显示：

1. 月度收入与利润双柱状图，卡片右上角切换 `6月 / 12月 / 全部`，默认 `6月`。
2. 图例：收入、利润；出现亏损月份时追加亏损。
3. 原有「月度表现」列表，仍按月份从新到旧排列，保持不变。

图表横轴标签使用「年-月」（例如 `2026-09`）。连续月份补零，横轴时间从左到右递增，最右侧为最近月份；月份较多、内容宽度超过屏幕时横向滚动并初始定位到最近月份。没有月度数据时卡片内显示「暂无月度数据」，切换按钮保留可用。

### 维修品牌

- 编辑页「客户信息」卡片中，在「维修设备」下方新增「品牌」输入框，右侧下拉可从常用品牌选择，也可自由输入。
- 更多页在「常用维修设备」下方新增「常用品牌」管理卡片，默认内置 20 个常见电视品牌，可增删。
- 首页最近维修卡片与台账列表卡片展示品牌标签；品牌字段纳入台账搜索关键字。

## 数据设计

### 图表

按月与按日共用同一套图表模型，避免两处绘图逻辑分叉：

- `BarChartPoint`：一个时间分组的标签、收入与利润。
- `BarChartScale`：纵轴正负方向的量程。
- `LedgerBarChart`：双柱绘制、零线、图例、横向滚动与最新分组定位。

按日与按月各自只负责把汇总结果转换为数据点与标签格式。

新增两个纯领域函数：

- `summariesByMonthAscending`：全部月度汇总，按时间从旧到新排列。
- `summarizeRecentMonths`：以指定月份为最后一个月，生成连续 N 个月的汇总，缺少记录的月份补零。

### 品牌字段

- 维修记录新增品牌文本字段，默认空字符串。
- 数据库版本从 3 升级到 4，通过 `ALTER TABLE repair_records ADD COLUMN brand TEXT NOT NULL DEFAULT ''` 保留既有数据。
- 品牌选项与地址、维修设备、故障现象、维修项目一致，保存在本机 `SharedPreferences` 中。

## Excel 与备份

导出表头改为自描述，覆盖全部业务字段：

`日期 · 客户姓名 · 品牌 · 联系电话 · 客户地址 · 维修设备 · 故障现象 · 维修项目 · 收费 · 零件费 · 利润 · 保修天数 · 备注`

导入改为按表头名称匹配列，不再依赖固定列位置：

- 中英文表头均可识别，列顺序可以任意调整。
- 旧版导出文件（`日期 / 地址 / 配件 / 故障现象 / 收费 / 零件费 / 电话 / 备注 / …`）继续可导入。
- 表头完全无法识别时退回旧版固定列顺序，避免整表被跳过。
- 导出中的派生列（利润）与保修天数列按名称识别，不会被误读为收费或零件费。

备份 JSON 增加品牌字段；解码旧备份时品牌缺省为空字符串，不影响历史备份还原。

## 状态与异常

- 没有任何维修记录时，按月图表显示 6 个零值月份，下方显示「暂无月度统计」空状态。
- 成本为空的记录仍按 0 计算成本，与既有统计口径一致。
- 品牌允许留空，留空时列表不显示品牌标签，也不影响搜索与导出。
- 数据库升级只新增列，不修改既有列，历史记录的品牌为空字符串。

## 测试与验收

领域与逻辑单元测试覆盖：

- 月度图表量程：覆盖收入、正利润与负利润，空输入与全零输入返回稳定量程。
- 图表数据点标签格式：按日为 `MM-dd`，按月为 `yyyy-MM`，并保持输入顺序。
- 月度范围枚举的标签、标题与月数，以及「全部」不限制月数。
- 最近 N 个月连续、补零、跨年边界正确。
- 全部月度汇总按时间从旧到新排列。
- 品牌在记录与实体之间往返一致。
- 品牌默认项数量与内容。
- 导出表头包含全部业务字段，导出后再导入全字段无损（含品牌、客户姓名、维修设备、保修天数）。
- 旧版中文表头与英文表头文件仍可导入；派生利润列不被误读；列顺序打乱仍可识别；无法识别的表头退回固定列位置。
- 备份往返保留品牌；解码不含品牌字段的历史备份不报错。

完成后运行全部 JVM 单元测试与 Debug APK 构建，并在模拟器上安装新版验证：品牌录入、常用品牌管理、按月图表切换、以及从旧版数据库升级后历史记录不丢失。应用版本从 1.14 升级为 1.15，版本号从 15 升级为 16，并生成 `电视维修记账_v1.15_debug.apk`。
