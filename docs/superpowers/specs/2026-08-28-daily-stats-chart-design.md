# 按日统计与经营图表设计

## 目标

在现有经营统计页面加入按日统计，并用最近 7 个自然日的双柱状图直观比较每日收入和利润。保留现有按月、维修项目和故障类型统计。

## 界面设计

统计页标签顺序调整为：按日、按月、维修项目、故障类型。进入统计页时默认打开“按日”。

“全部经营数据”总览保持现状，继续显示全部记录的总收入、总利润、总成本和维修单数。

按日页在总览下方依次显示：

1. 最近 7 个自然日的收入与利润双柱状图。
2. 图例，明确区分收入和利润。
3. 全部日期的每日统计明细，按日期从新到旧排列。

每日明细显示日期、维修单数、收入、零件费和利润。最近 7 天内没有维修记录的日期在图表中显示为 0，保证日期连续；这些空日期不加入下方全部明细列表。

正常利润使用现有利润绿色。利润小于 0 时使用现有危险红色，并从图表零线向下绘制。收入柱保持现有维修蓝色。图表横轴使用月日格式，在小屏幕上仍显示完整 7 个日期。

## 数据设计

新增日统计模型，包含：日期、维修单数、收入、成本和利润。

新增两个独立的领域函数：

- 按日期汇总全部记录，结果按日期从新到旧排列。
- 以指定结束日期生成连续 7 天图表数据，并为缺少记录的日期补零。

收入为当日 `chargedAmountCents` 合计；成本为当日非空 `partsCostCents` 合计；利润为收入减成本。统计直接基于 Room 提供的现有维修记录列表，不修改数据库结构。

## 图表实现

使用 Jetpack Compose 原生绘制能力实现柱状图，不增加第三方图表依赖。

图表组件接收连续 7 天日统计数据，只负责布局、比例换算、颜色和标签绘制。比例范围同时覆盖收入、正利润和负利润；所有值为 0 时仍显示稳定的坐标区域和日期标签，不产生除零或无效尺寸。

图表不依赖横向滚动，不加入缩放或复杂手势。用户可直接通过下方每日明细查看精确金额。

## 状态与异常

- 没有任何维修记录时，图表显示连续 7 天的零值，并显示“暂无按日统计”空状态。
- 仅有历史记录且最近 7 天没有数据时，图表显示最近 7 天零值，下方仍显示历史每日明细。
- 成本为空按 0 计算，与现有统计口径一致。
- 亏损日期使用红色利润柱和红色利润文字。

## 测试与验收

领域单元测试覆盖：

- 同一天多条记录正确合并。
- 每日收入、成本、利润和单数计算正确。
- 全部日统计按日期从新到旧排列。
- 最近 7 天数据按日期连续排列并补零。
- 结束日期边界和亏损利润正确处理。

完成后运行全部 JVM 单元测试和 Debug APK 构建。应用版本从 1.12 升级为 1.13，版本号从 13 升级为 14，并生成 `电视维修记账_v1.13_debug.apk`。
